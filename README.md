# Customer Shopping Behavior Analysis

A data analytics project focused on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, product performance, and business insights.

## Project Overview

In this project, I worked with a customer shopping behavior dataset and performed data cleaning, preprocessing, SQL-based analysis, and exploratory data analysis to transform raw customer data into meaningful business insights.

The project demonstrates the complete data analytics workflow, from handling raw data to extracting actionable insights that can support data-driven business decisions.

## Key Tasks Performed

* Cleaned and preprocessed the customer shopping dataset using Python and Pandas.
* Handled missing values using appropriate statistical techniques.
* Standardized column names and transformed data into an analysis-friendly format.
* Created meaningful categories such as age groups.
* Converted purchase frequency values into numerical representations.
* Performed SQL queries to analyze customer and product-level information.
* Used aggregation functions such as `AVG()`, `COUNT()`, `SUM()`, and `GROUP BY`.
* Analyzed product ratings, purchase behavior, and customer segments.
* Identified patterns and trends from the dataset.
* Prepared the cleaned data for further analysis and visualization.
